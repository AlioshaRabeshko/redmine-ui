# Handoff реалізації

- Спільна документація не зберігає production URL, токени, IDs, імена користувачів, лічильники даних або результати перевірки прав доступу.
- Backend URL і токен задаються локально через env. Проєктні, статусні, custom-field та option IDs отримуються з Redmine під час читання; workflow label names задаються окремими локальними env-параметрами.
- Доступність metadata залежить від інсталяції та прав. Невідомі значення не отримують вигаданих назв, а частковий кеш не вважається повним переліком.
- Розробницькі перевірки зовнішніх записів використовують isolated demo або mock transport.
- Поточні інструкції з запуску та архітектури: README.md і TECHNICAL.md.
